# Ripples-DIY

Ripples is another Mutable Instruments module built thanks to Émilie's open sourced designs. It's a 'classic' 4-pole multimode analog filter. A full description of the production version of Ripples is available from Mutable Instruments: [http://mutable-instruments.net/modules/ripples](http://mutable-instruments.net/modules/ripples).

Thanks to Émilie's commitment to open sourcing his designs, the hardware design for Ripples is available for use in personal projects via her [git repository](https://github.com/pichenettes).

## Current status

* PCB: completed pcb and tested
* Panel: completed
